# Experiment records

This directory is the append-only history of executed and seriously considered
Firewing experiments. Prospective work belongs in
[`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md).

Each record is named `FW-NNNN-short-name.md`; identifiers are sequential and are
never reused. Copy [`TEMPLATE.md`](TEMPLATE.md) before execution, freeze its
hypothesis and gates in a clean commit, and preserve negative, aborted, and
reversed results.
